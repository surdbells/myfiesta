# The myfiesta brand

Supplied by the owner, 2026-08-27. The mark is a microphone with a gold
flash and collar; the wordmark sets "myfiesta" lowercase with the mic
dotting the i.

- `mark-source.png` — the mic, 3200×3201, transparent
- `wordmark-source.png` — the full lockup (GIF re-extensioned; white ground)

Colours, sampled from the mark and anchored in `packages/tokens/tokens.json`:

- green `#0e753b` = `color.brand.600` = `--primary`
- gold  `#d0cb29` = `color.gold.400`

Derived sizes live in each app's `public/brand/` (32/64/192/512), produced by
Chrome canvas downscale (`tools/` has the pattern). Regenerate from the source
here rather than resizing a resize.
